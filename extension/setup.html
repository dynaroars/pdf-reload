Install the helper

Open a terminal and paste this command. It installs the helper for your account and does not need administrator access:

curl -fsSL https://github.com/dynaroars/pdf-reload/releases/latest/download/install-pdf-reload.sh | bash

The script checks its downloads and explains any missing system requirement. Python is handled by the installer; you do not need to run the Python helper yourself.

After installation, return to your PDF and click the toolbar button again. The helper runs only while a PDF is being watched and sends file-change notices, never PDF contents.
